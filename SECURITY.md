# Security Policy

## Supported Versions

PaperScreen is currently in its first release. Security updates will be provided for the latest stable version.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Security Issue

If you discover a security vulnerability in PaperScreen, please do not open a public GitHub issue.

Instead, report it privately by:

- Opening a GitHub security advisory (preferred), or
- Contacting the project maintainer through the GitHub profile/contact information.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Affected version
- macOS version
- Any relevant logs or screenshots

## Response Timeline

We will try to:

- Acknowledge security reports within 7 days
- Investigate and assess the impact
- Provide fixes or mitigation guidance when applicable
- Publish security updates through GitHub Releases

## Scope

Security reports related to PaperScreen may include:

- Application crashes caused by malicious input
- Unexpected privilege escalation
- Unauthorized access to user data
- Vulnerabilities in update or installation mechanisms
- Issues affecting system stability or privacy

## Out of Scope

The following are generally not considered security vulnerabilities:

- Feature requests
- UI/UX issues
- Performance improvements
- Cosmetic issues
- Issues requiring physical access to the machine

## Disclosure Policy

Please allow reasonable time for investigation and remediation before publicly disclosing security issues.

We appreciate responsible disclosure and thank all researchers and users who help improve PaperScreen.
